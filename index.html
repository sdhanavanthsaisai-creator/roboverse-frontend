01

PROBLEM STATEMENT

The maze refuses
to sit still.

ROBOTO is dropped at the mouth of a maze it has never seen. The corridors it mapped on the last run may not exist on this one — a route can be sealed mid-drive, an obstacle can simply appear, and the path that looks shortest on paper can hide the slowest stretch of floor.

Success is not finding the exit once — it is arriving sooner every time the maze changes.

So the rover carries no map and no human. It carries sensors, mathematics and a memory: it fuses what it perceives into a map, plans through that map, reacts when the map betrays it, and scores every attempt so the next one starts smarter.

Up to five kilograms of payload, zero guidance from the outside, and one standing order: find the exit — then find it faster.

EQ·01

PLANNER — A* SEARCH

The rover expands the cell with the cheapest total promise: cost already paid, plus an estimate of cost to go. Mud squares cost ×4 — which is exactly why the shortest-looking route is not always the fastest one.

EQ·02

HEURISTIC — MANHATTAN

Grid distance to the exit. It never overestimates on a 4-connected grid, which guarantees the plan A* returns is truly optimal — not just plausible.

EQ·03

MAPPING — OCCUPANCY LOG-ODDS

Every sonar ping nudges a cell's log-odds a little, so one noisy reflection can never rewrite the map. Evidence accumulates; certainty is clamped.

EQ·04

PERCEPTION — COMPLEMENTARY FILTER

The gyro is fast but drifts; the magnetometer and wheel encoders are slow but stable. α blends them into a heading estimate that is quick and never wanders far from the truth.

EQ·05

CONTROL — PID LOOP

PID closes the loop between the planned line and the wheels: proportional kicks, integral patience, derivative restraint. The chassis stays glued to the route.

EQ·06

LEARNING — Q-UPDATE

After each run, the value of every move drifts toward the reward it actually produced. Attempt ten takes shortcuts attempt one never knew existed.
